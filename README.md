# DP 背包 OJ

基于《背包问题九讲》（崔添翼，CC BY-NC-SA）的个人自学用在线评测与练习平台。
技术方案详见 `docs/DP-OJ-技术方案与功能大纲.md`，整体验收详见 `docs/验收清单.md`。

## 快速开始

```bash
pnpm install
pnpm dev        # server: http://localhost:3000/api/system/health ｜ web: http://localhost:5173
```

打开 http://localhost:5173 即可开始刷题。

## 功能

- **题库**：九讲对应 12 道基础题（A1-A12）+ 8 道扩展题（B1-B8），题面含 LaTeX 公式
- **在线编写**：Monaco 编辑器，支持 C++14 / Python 3 / Go / Java 语法高亮与草稿自动保存
- **即时测试**：「运行样例」一键跑题面样例；「自定义测试」任意 stdin 快速运行（四语言 <2s）
- **提交判题**：编译 → 逐组沙箱运行 → 输出比对（行末空白不敏感），首败组即终态
- **结果反馈**：判题结果码 + 总耗时 + 逐组明细 + CE 编译器全文 + WA 期望/实际对比 + RE stderr
- **提交记录**：最近 50 条提交，点击查看逐组判题详情
- **系统状态**：判题机工具链自检（/system 页面）

## 判题结果码

| 码 | 含义 |
|---|---|
| AC | 通过 |
| WA | 答案错误（输出超限 OLE 亦归 WA） |
| TLE | 超出时间限制（单组限时 x 语言系数） |
| MLE | 超出内存限制 |
| RE | 运行时错误（非零退出） |
| CE | 编译错误（附编译器全文） |
| SE | 系统错误 |

## 沙箱模式

- **本地进程（默认）**：spawn 子进程 + 超时强杀进程树 + 输出截断，零外部依赖；Windows 下内存限制为尽力而为。
- **Docker 容器（可选）**：精确内存限制（--memory）、断网（--network=none）、限核限进程数。启用：

```powershell
.\data\docker\build-judge-image.ps1   # 构建判题镜像 dp-oj/judge-env（首次需 Docker Desktop）
$env:JUDGE_RUNNER = 'docker'            # 切换到容器沙箱
pnpm dev:server
```

## 目录

- `apps/web`  React + Vite 前端（Monaco 编辑器）
- `apps/server` NestJS 后端（题库/提交/判题编排/判题队列）
- `packages/judge` 判题引擎（编译/沙箱/比对/首败终态/CLI/DockerRunner）
- `packages/common` 判题结果码、语言配置、共享类型
- `data/problems` 题库（题面 + 配置 + 测试数据）
- `data/seeds` 测试数据生成器（固定种子可复现）与 C++ 参考解
- `data/docker` 判题镜像 Dockerfile 与构建脚本

## 常用命令

```bash
pnpm dev                                   # 前端 + 后端
pnpm --filter @dp-oj/judge test            # 判题引擎单元测试（15 项）
node packages/judge/dist/cli.js --lang cpp --source x.cpp --cases dir   # 判题 CLI
node data/seeds/generators/gen-b1-b8.mjs   # 重新生成测试数据（固定种子，另见 gen-c1-c5 / gen-c6-c10 / gen-c11-c14）
```
