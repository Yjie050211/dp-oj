## 题目描述

小明在整理装备，共有 **N 件**装备，第 $i$ 件占用空间 $C_i$、价值 $W_i$。装备之间存在**依赖关系**：第 $i$ 件装备的「前置装备」编号为 $p_i$（$p_i = 0$ 表示没有前置，可以独立选择）。选择一件装备前，**必须先选择它的前置装备**（前置装备的前置也要先选，依此类推）。

依赖关系构成若干棵树的**森林**（不会成环）。背包容量为 **V**，求最大总价值。

这是「有依赖的背包问题」的一般形式（第 7 讲 §7.3 的森林依赖）。

## 输入格式

第一行两个整数 $V$ 和 $N$。

接下来 $N$ 行，每行三个整数 $C_i$、$W_i$、$p_i$（$0 \le p_i < i$）。

## 输出格式

输出一个整数，表示最大总价值。

## 数据范围

- $1 \le N \le 50$，$1 \le V \le 1000$
- $1 \le C_i \le V$，$1 \le W_i \le 1000$

## 提示

添加虚拟根 0 连接所有 $p_i=0$ 的根装备，转化为树形背包：$dp[u][v]$ 表示以 $u$ 为根的子树（必选 $u$）在容量 $v$ 下的最大价值。每个子树相当于一件**泛化物品**，父子通过分组背包合并。
